# Network Security Specialist 

## Network Traffic Analysis

This project was completed as part of the YuvaIntern Network Security Specialist internship.

### Task Objective

The objective of this task was to analyze sample network traffic using Wireshark, understand communication patterns, identify source and destination addresses, examine protocols and ports, and identify unusual network activity that may require further investigation.

### Tools Used

- Wireshark
- Kali Linux
- Authorized Wireshark sample capture files

### Analysis Performed

The analysis included:
- Packet and protocol examination
- Source and destination IP analysis
- Protocol hierarchy analysis
- Endpoint analysis
- TCP/UDP communication analysis
- Identification of unusual communication patterns
